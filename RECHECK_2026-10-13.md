## New bugs found

1. HIGH: "Describe it" cannot work. The Groq model `llama-3.3-70b-versatile` is not available. Default is set at
   `supabase/functions/estimate-food-macros/index.ts:16` and `supabase/functions/estimate-meal/index.ts:16`
   (`GROQ_MODEL` env override), and hardcoded at `supabase/functions/generate-daily-brief/index.ts:10`, so the
   daily brief likely fails too. Fix: set a current model via the `GROQ_MODEL` secret and update the defaults;
   also stop surfacing raw provider JSON (return a short "Estimate unavailable" message, log the detail).
2. MEDIUM: kebab hides "Cancel entire workout". `src/components/workouts/ExerciseCard.jsx:~763` caps the menu at
   `max-h-[min(60vh,320px)]` with 8 items. Fix: raise to `min(70vh,480px)` or move Cancel out of the kebab.
3. MEDIUM: Add Food sheet header/close X scroll away while the keyboard is up (the whole sheet scrolls as one
   container, `src/components/ui/dialog.jsx` + `FoodTracker.jsx` add dialog). Fix: make the dialog header
   sticky/shrink-0 with the scroller inside, as the markup already intends.
4. MEDIUM: keyboard stays open behind the barcode scanner from Fuel's camera button.
   `src/components/nutrition/BarcodeScanner.jsx` (the `activeElement.blur()` in the open effect) runs before the
   Add Food search input autofocuses. Fix: blur in `requestAnimationFrame`/after dialog mount, or skip
   autofocus when opening via scan.
5. MEDIUM: result ranking still poor. For "banana" the first result is "Bananas, dehydrated, or banana powder",
   for "chicken breast" it is "Chicken breast tenders, breaded, uncooked". The prefix rank in the search effect
   (`FoodTracker.jsx`, `rank()`) favours any prefix match. Fix: prefer `Foundation`/`SR Legacy` raw items and
   push words like dehydrated, breaded, powder, canned, cooked to the end.
6. LOW: after picking a result, Amount and Meal Type are still under the sticky Add Food bar (below the fold).
   `15b/03-picked.png`. Fix: put Amount and Meal above Manual Entry.
7. LOW: USDA names are title-cased on pick ("Bananas, Raw").
8. LOW: after picking a food the "Edit base values, per g" fields show totals for the entered amount (223 for
   250 g), not per-gram values, so the label contradicts the numbers. `15d/08-amount-250.png`.
9. INFO: on this branch the Coach card on an empty Quick Workout still says "RIR 0.0 and e1RM trending down ...
   Staying at 270 lbs" (cross-branch engine change). `19/11`.
